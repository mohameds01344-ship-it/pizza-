# Pizza House — Apple-inspired restaurant website

A responsive static restaurant website made with HTML, CSS, and vanilla JavaScript. It can be hosted on GitHub Pages.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Customize before publishing
Open `script.js` and edit:

- `CONFIG.whatsappNumber`: replace `201000000000` with the restaurant's WhatsApp number in international format, digits only (Egypt example: `201012345678`).
- `CONFIG.deliveryFee`: set the delivery fee in EGP.
- `PRODUCTS`: change product names, categories, prices, descriptions, tags, and image URLs.

The current menu and prices are demo content. Replace them with the restaurant's real details before launch. Food photos load from Unsplash and therefore require an internet connection.

## Publish on GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and `README.md` to a repository's root, then enable GitHub Pages from the repository settings.
